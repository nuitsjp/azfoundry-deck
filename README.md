# AzFoundry Deck

Microsoft Foundry のモデルとデプロイを管理するデスクトップアプリの正式実装リポジトリーです。提供された仮実装を参考に、モックで仕様を合意してから機能単位で実処理へ接続します。

## 現在の状態

プロジェクトテンプレート配布版2を適用し、実装前の文書を整備しました。アプリケーションコード、モック、開発・ビルド環境はまだありません。仮実装の仕様候補と過去の検証記録は、正式版の合意や検証実績とは区別して管理します。

進捗状況、最初に取り組む機能、未決事項は [PLAN.md](PLAN.md) を参照してください。

## 実行・確認方法

現時点でこのリポジトリーを起動・ビルドするコマンドはありません。文書の確認方法と今後整備する実行手順は [プロジェクト定義の実行手順](docs/project.md#commands) を参照してください。
