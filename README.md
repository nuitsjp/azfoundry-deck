# AzFoundry Deck

Microsoft Foundry のモデルとデプロイを管理するデスクトップアプリのリポジトリです。画面と操作はゼロから検討し、モックによる仕様合意を経て機能単位で実処理へ接続します。

## 現在の状態

F1のデプロイ一覧とF2のモデル候補参照は、モック・実Azure読取を実装済みです。モックを明示しない起動では、サインイン済みAzure CLIを使います。

現在は「モデルを追加する」仮UIを利用者と確認中です。リソースグループ・Foundryの新規入力、モデル候補の非同期ロードを再現しますが、実Azureへの作成・保存・一覧反映は未実装です。次は最新版UIの認識合わせを続け、実作成前に新規Foundryと候補取得の順序・費用・失敗時の扱いを確定します。検証済みの範囲と未決事項は [PLAN.md](PLAN.md) を参照してください。

進捗状況、最初に取り組む機能、および未決事項は [PLAN.md](PLAN.md) を参照してください。

## 実行・確認方法

環境構築・ビルドの確認済み手順と、互換性確認用画面の起動方法は [プロジェクト定義の実行手順](docs/project.md#commands) を参照してください。
