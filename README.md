# AzFoundry Deck

Microsoft Foundry のモデルとデプロイを管理するデスクトップアプリのリポジトリです。画面と操作はゼロから検討し、モックによる仕様合意を経て機能単位で実処理へ接続します。

## 現在の状態

F1 モック用の構成を採用し、互換性確認用の最小画面と Go サービスで、コード生成・型検査・Windows ビルドを確認しました。ヒアリングにより、アカウント横断のデプロイ一覧と絞り込みを中心とする主要要件も合意済みです。F1 全シナリオのモック、モックによる動作合意、Azure 実接続は未着手です。

進捗状況、最初に取り組む機能、および未決事項は [PLAN.md](PLAN.md) を参照してください。

## 実行・確認方法

環境構築・ビルドの確認済み手順と、互換性確認用画面の起動方法は [プロジェクト定義の実行手順](docs/project.md#commands) を参照してください。
