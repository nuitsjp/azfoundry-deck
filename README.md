# AzFoundry Deck

Microsoft Foundry のモデルとデプロイを管理するデスクトップアプリのリポジトリです。画面と操作はゼロから検討し、モックによる仕様合意を経て機能単位で実処理へ接続します。

## 現在の状態

F1 の画面・操作とモックの動作合意を完了し、Azure SDK for Go による実接続の読取境界も実装しました。モックを明示しない起動では、サインイン済み Azure CLI の対象サブスクリプションを使って Foundry アカウントとデプロイを取得します。実接続の認証・権限・全件性・性能には未検証範囲が残るため、進捗と確認結果は [PLAN.md](PLAN.md) に記録しています。

進捗状況、最初に取り組む機能、および未決事項は [PLAN.md](PLAN.md) を参照してください。

## 実行・確認方法

環境構築・ビルドの確認済み手順と、互換性確認用画面の起動方法は [プロジェクト定義の実行手順](docs/project.md#commands) を参照してください。
