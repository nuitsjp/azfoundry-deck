# デプロイモデルを更新する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が Foundry 一覧とデプロイ済みモデルを表示した Home画面で、「Refresh models」ボタンを押す。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | モデル一覧の見出しの右にある「Refresh models」ボタンを押す。 | 「Refreshing models」という進捗モーダルを開き、選択中の Foundry のすべてのデプロイ済みモデルを Azure から取得する。 |
| 2 | モーダルで取得の進捗を確認する。 | 「Deployments」を「Loading」で表示し、選択中の Foundry の名称と累積件数を表示する。全モデルの取得後に「Completed」にする。 |
| 3 | 更新後のデプロイ済みモデルを確認する。 | 取得したモデルと取得日時をメモリに保持して進捗モーダルを閉じ、モデル一覧・モデル件数・最終取得日時を更新する。 |

## 受け入れ条件

- 選択中の Foundry のデプロイ済みモデルを Azure から全ページ取得する。
- Foundry 一覧を再取得せず、Foundry 一覧の取得の進捗を表示しない。
- 進捗モーダルは「Deployments」の1行だけを表示し、「Loading」「Completed」、選択中の Foundry の名称、累積件数を示す。取得中の行には回転表示を付け、結果は行の右側に表示する。
- 取得した全モデルと最終取得日時はメモリにだけ保持し、画面の内容と一致させる。デプロイ済みモデルは保存せず、状態ファイルの内容は変えない。
- モデルの取得がすべて成功した後に結果を確定する。
- 取得が完了するまで、更新前のモデル表示を維持する。
- アプリケーションを再起動した場合や、別の Foundry へ変更して戻った場合は、更新後の一覧を引き継がず、Azure から取得し直した一覧と取得日時を表示する。
