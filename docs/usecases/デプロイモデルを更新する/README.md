# デプロイモデルを更新する

## 主アクター

Foundry の運用者。

## 目的

選択中の Foundry のデプロイ済みモデルを Azure から取得し直し、Home画面のモデル一覧を最新にする。

## 前提

Azure にログイン済みで、Home画面に選択済み Foundry のデプロイ済みモデルを表示している。

## 共通の受け入れ条件

- モデル一覧の見出し「デプロイ済みモデル」の右に「Refresh models」ボタン（マウスオーバー時にツールチップで名称を表示するアイコンボタン）を置く。
- モデルの更新中は、閉じるボタン・Escape・モーダル外クリックで進捗モーダルを閉じず、Foundry の変更と更新操作を受け付けない。
- モデル件数と最終取得日時の表示は「デプロイモデルを閲覧する」の共通の受け入れ条件に従う。
