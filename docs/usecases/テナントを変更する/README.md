# テナントを変更する

## 主アクター
Azure にログイン済みの Foundry 運用者。

## 目的
認証済みのアカウントを維持したまま、Azure リソース操作の対象テナントを変更する。

## 前提
テナント一覧に2件以上存在し、利用対象のテナントが選択済みで、Home を表示している。

## 共通の受け入れ条件
- アカウントを切り替えずに、利用対象のテナントだけを変更する。
- 同じテナントを選んだ場合は、取得や保存を行わない。
- 変更先テナントのトークン取得または選択保存に失敗した場合は、変更前のテナントと表示を維持し、エラーコード `SELECT_TENANT_FAILED` と理由を表示する。トークンはブラウザーを開かずに取得する。
- 変更処理中は、追加のテナント変更・Foundry の変更・更新操作を受け付けない。
- 選択保存の成功後に、変更前のテナントの Foundry とモデルの表示を消し、変更前のテナントのものを表示しない。
- 切り替え後の Foundry 閲覧に失敗した場合は、変更先テナントの画面にエラーを表示する。
- 再起動後は、最後に選択したテナントを復元する。
