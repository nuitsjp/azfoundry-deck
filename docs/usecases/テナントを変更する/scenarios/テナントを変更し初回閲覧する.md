# テナントを変更し初回閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件
ログイン済みの利用者が、Home を表示した状態で現在と異なるテナントを選択し、同じアカウントと変更先テナントの保存済み閲覧結果が存在しない。トークン取得・選択保存・閲覧結果の取得とファイル保存が成功する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | ヘッダーのテナントプルダウンを開く | サインイン時に取得したテナント一覧を表示する。現在のテナントを選択済みとして示す。 |
| 2 | 別のテナントを選ぶ | プルダウンを閉じ、変更先テナントのトークンを取得して選択を保存する。 |
| 3 | （操作なし） | 選択保存の成功後に対象テナントを切り替え、変更前の Foundry・モデル表示を消す。変更先の保存済み閲覧結果がないことを確認し、進捗モーダルを開いて Foundry 一覧と選択先のモデルを Azure から取得する。 |
| 4 | 完了した Foundry とデプロイ済みモデルを確認する | 取得結果を変更先テナントの保存先へ保存する。保存成功後に進捗モーダルを閉じ、変更先テナントの Home に表示する。 |

## 受け入れ条件
- 変更先の保存済み閲覧結果がない場合は、既存の「デプロイモデルを初回閲覧する」と同じ取得・進捗モーダル・保存を行う。
- 取得結果は変更先のアカウントとテナントの保存先に保存し、画面の内容と一致させる。
- 変更前のテナントの保存済み閲覧結果は保持し、戻ったときにファイルから表示できるようにする。
