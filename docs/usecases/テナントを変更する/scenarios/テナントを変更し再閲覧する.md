# テナントを変更し再閲覧する

- 種別: 拡張
- UI確認: 要

## 分岐条件
ログイン済みの利用者が、Home を表示した状態で現在と異なるテナントを選択し、同じアカウントと変更先テナントの保存済み閲覧結果が存在して読み込みに成功する。トークン取得と選択保存が成功する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | 変更先に保存済みの閲覧結果がある状態で、ヘッダーのテナントプルダウンを開く | サインイン時に取得したテナント一覧を表示する。現在のテナントを選択済みとして示す。 |
| 2 | 別のテナントを選ぶ | プルダウンを閉じ、変更先テナントのトークンを取得して選択を保存する。 |
| 3 | （操作なし） | 選択保存の成功後に対象テナントを切り替え、変更前の Foundry・モデル表示を消す。変更先の保存済み Foundry 一覧・選択・モデルを読み込む。進捗モーダルは表示しない。 |
| 4 | 変更先の Foundry とデプロイ済みモデルを確認する | 保存された選択を維持し、その Foundry の保存されたすべてのデプロイ済みモデルを表示する。 |

## 受け入れ条件
- サブスクリプション・Foundry・モデルの Azure からの取得を実行しない。
- 取得の進捗モーダルを表示しない。
- 表示する Foundry 一覧・選択・モデルは、保存内容と完全に一致する。
- 保存された Foundry の選択を維持し、最初の Foundry に変更しない。
- 読み込んだ保存済みの閲覧結果を再保存しない。
