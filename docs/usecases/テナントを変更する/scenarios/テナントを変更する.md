# テナントを変更する

- 種別: 主成功
- UI確認: 要

## 開始条件
ログイン済みで、テナント一覧に2件以上存在する。利用対象のテナントが選択済みで、Home を表示している。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | ヘッダーのテナントプルダウンを開く | サインイン時に取得したテナント一覧を表示する。現在のテナントを選択済みとして示す。 |
| 2 | 別のテナントを選ぶ | 変更先テナントでの操作に必要なトークンを取得し、選択を保存する。処理中は追加のテナント変更を受け付けない。 |
| 3 | （操作なし） | 選択保存の成功後に対象テナントを切り替え、変更前の Foundry・モデル表示を消す。変更先テナントの Home 表示を開始する。 |

## 受け入れ条件
- アカウントを切り替えずに、利用対象のテナントだけを変更する。
- 同じテナントを選んだ場合は、取得や保存を行わない。
- トークン取得または選択保存に失敗した場合は、変更前のテナントと表示を維持し、エラーのコードと理由を表示する。
- 切り替え後に、変更前のテナントの Foundry やモデルを表示しない。
- 同じアカウント・変更先テナントの保存済み閲覧結果があれば復元し、なければ既存の初回閲覧処理を行う。
- 切り替え後の Foundry 閲覧に失敗した場合は、変更先テナントの画面にエラーを表示する。
- 再起動後は、最後に選択したテナントを復元する。
