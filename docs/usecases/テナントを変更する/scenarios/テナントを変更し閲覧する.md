# テナントを変更し閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件
ログイン済みの利用者が、Home を表示した状態で現在と異なるテナントを選択し、同じアカウントと変更先テナントの保存済み Foundry 一覧・選択済み Foundry が存在しない。トークン取得・選択保存・Foundry 一覧とデプロイ済みモデルの取得・ファイル保存が成功する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | ヘッダーのテナントプルダウンを開く | サインイン時に取得したテナント一覧を表示する。現在のテナントを選択済みとして示す。 |
| 2 | 別のテナントを選ぶ | プルダウンを閉じ、変更先テナントのトークンを取得して選択を保存する。 |
| 3 | （操作なし） | 選択保存の成功後に対象テナントを切り替え、変更前の Foundry・モデル表示を消す。変更先の保存済み Foundry 一覧・選択がないことを確認し、進捗モーダルを開いて Foundry 一覧と選択先のデプロイ済みモデルを Azure から取得する。 |
| 4 | 完了した Foundry とデプロイ済みモデルを確認する | Foundry 一覧・選択・Foundry 一覧の最終取得日時を変更先テナントの保存先へ保存する。保存成功後に進捗モーダルを閉じ、変更先テナントの Home に表示する。 |

## 受け入れ条件
- 変更先の保存済み Foundry 一覧・選択済み Foundry がない場合は、既存の「デプロイモデルを閲覧する」と同じ取得・進捗モーダル・保存を行う。
- 変更先の保存先に保存するのは Foundry 一覧・選択済み Foundry・Foundry 一覧の最終取得日時だけとし、画面の内容と一致させる。デプロイ済みモデルの一覧は保存せず、`foundry-models` ディレクトリも作らない。
- 変更前のテナントの保存済み Foundry 一覧・選択済み Foundry は保持し、変更しない。
- 変更先のテナントに保存済みの Foundry 一覧・選択済み Foundry がある場合は、それを使い、Foundry 一覧を取得せず、保存された選択を維持して最初の Foundry に変更しない。選択済み Foundry のデプロイ済みモデルだけを Azure から取得し、保存済みの Foundry 一覧と最終取得日時は変更しない。
- 変更前のテナントのデプロイ済みモデルを、変更先テナントの画面に表示しない。
