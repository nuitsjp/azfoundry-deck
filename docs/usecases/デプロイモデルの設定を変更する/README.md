# デプロイモデルの設定を変更する

## 主アクター

Azure にログイン済みの Foundry 運用者。

## 目的

Home画面で選択中の Foundry にある既存のデプロイモデルの設定を Azure 上で変更し、一覧と明細を最新にする。

## 前提

Home画面で Foundry が選択され、そのデプロイ済みモデル一覧が表示されている。対象デプロイの明細が表示されている。

## 共通の受け入れ条件

- 変更対象は、選択中の Foundry に属するデプロイモデル1件とする。
- 変更できるのは Version、Capacity、Upgrade policy とする。Deployment name、Model、SKU は変えない。
- Azure 上の変更が完了するまで、一覧と保存済みファイルは変更しない。
- 変更成功後は、Azure からデプロイ済みモデルを取得し直して保存し、一覧・件数・最終取得日時を最新化する。同じデプロイを選択したまま、明細を Azure から取り直す。
- 変更失敗時は、一覧と保存済みファイルを変更せず、エラーコード `DEPLOYMENT_UPDATE_FAILED` と理由を表示し、再試行できるようにする。
