# 一覧からデプロイモデルの設定を変更する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が、Foundry 一覧とデプロイ済みモデルを表示した Home画面で、一覧からデプロイを選んで右側の明細を表示し、明細見出しの Edit deployment を押す。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 変更したいモデルを一覧から選び、明細見出しの Edit deployment を押す。 | 設定モーダルを開く。開くたびに共有クォータ一覧だけを Azure から取得し直す間（モデル定義は保持した結果を使う）、モーダル内にプログレスを表示する。取得後、Deployment name、Model、SKU を変更できない表示とし、Version、Capacity、Upgrade policy に現在の値を入れる。 |
| 2 | Version、Capacity、Upgrade policy を調整して Update を押す。 | 設定モーダルを開いたまま、その前面に進捗モーダル（Step: Update）を重ねて表示し、Azure に変更を依頼して完了まで待つ。 |
| 3 | 変更後のデプロイ済みモデルと明細を確認する。 | 変更完了後に選択中 Foundry のデプロイ済みモデルを Azure から取得し直し、進捗モーダルと設定モーダルの両方を閉じる。モデル一覧・件数・最終取得日時を更新する。同じデプロイを選択したまま、明細を一覧の取得結果から再表示する。容量を変更した場合の共有クォータの更新は [保持規則](../../../design/UCP-1.md#モデルカタログと共有クォータの保持) に従う。 |

## 受け入れ条件

- 画面内の項目名・操作名・状態は英語で表示する。モーダルのタイトルは Edit deployment、実行ボタンは Update、取り消しは Cancel とする。
- Cancel または × を押した場合は、Azure への操作を行わず、変更前の一覧と明細を維持して設定モーダルを閉じる。
- Version の選択肢は、取得したそのモデルのバージョンとする。一覧に現在のバージョンが無い場合も、現在のバージョンを選択肢に含める。
- Upgrade policy の選択肢と表示名は明細と同じとする。`OnceNewDefaultVersionAvailable` は `Upgrade to new default`、`OnceCurrentVersionExpired` は `Upgrade on retirement`、`NoAutoUpgrade` は `No automatic upgrade` とする。
- Standard の Capacity は、明細と同じ割り当て可能上限を `現在値 / 最大値 TPM` で示し、数値入力とスライダーの両方で 1,000 単位に調整でき、双方が連動する。初期値は取得した現在の Capacity とする。初期値が上限を超える場合は、その値を表示したまま Update を無効にし、上限以内に直してから実行できる。
- Pay-as-you-go では Capacity を入力しない。
- 開いた時点の値から Version、Capacity、Upgrade policy のいずれも変わっていない場合、Update は無効とする。
- バージョン一覧または共有クォータ一覧の取得に失敗した場合は、変更を開始せず、モーダル内に `DEPLOYMENT_UPDATE_FAILED` と理由、および再試行を表示する。一覧と明細は変えない。
- Update の実行時は確認ダイアログを表示しない。進捗モーダルは Escape や外側クリックで閉じない。
- 変更の完了後は、変更前の一覧への手動反映ではなく、Azure から取得し直した結果で表示を置き換える。保存ファイルは変更せず、デプロイ一覧を保存しない。
- 変更に失敗した場合は進捗モーダルだけを閉じ、設定モーダルは入力値を保持したまま開いたままにする。モーダル内に `DEPLOYMENT_UPDATE_FAILED` と理由を表示し、修正して Update を再度押せる。権限不足もこの失敗に含め、理由に表示する。
- 別の Foundry へ変更して戻った場合も、Azure から取得した変更後のモデル一覧を表示する。
