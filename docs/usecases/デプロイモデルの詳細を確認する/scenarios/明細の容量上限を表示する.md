# 明細の容量上限を表示する

- 種別: 拡張
- UI確認: 要

## 分岐条件

「一覧からデプロイモデルの明細を表示する」でデプロイの行を押したとき、右側の `Capacity` の上限を表示する。その Foundry の上限情報はデプロイ一覧と並行して取得を開始しており、取得済みなら保持した結果を使い、取得中なら完了を待って明細を更新する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | デプロイの行を押す。 | 上限以外の項目を即時表示する。上限情報が取得済みなら上限も即時表示し、取得中なら `Capacity` の上限の位置に `Loading...` と回転表示を出す。行選択による取得の重複は行わず、取得中も一覧表示とモデル選択を受け付ける。 |
| 2 | 取得中の場合は、上限が表示されるまで待つ。 | 完了通知を受けて選択中の明細を更新し、`現在値 / 上限 単位` の上限を表示する。取得したモデル定義と共有クォータは、その Foundry の結果としてメモリだけに保持する。 |
| 3 | 同じ Foundry の同じデプロイまたは別のデプロイの行を押す。 | 保持した結果から上限を計算して即時表示する。Azure は呼ばず、`Loading...` を出さない。 |

## 受け入れ条件

- `Capacity` は設定済み容量と、共有クォータの残量を踏まえた割り当て可能上限を `現在値 / 上限 単位` の形式で表示する。上限は現在の割り当てに同じサブスクリプション・リージョン・モデル・デプロイ種別の共有クォータ残量を加えた値と、モデル・SKUの設定上限の小さい方とする。Standard 系は token レートを持つモデルは TPM、request レートのみのモデルは RPM、Provisioned 系は PTU とし、Standard の換算は取得したレートと設定容量から求める。上限はモデル・SKUの許可値または設定の刻みに合わせる。値には桁区切りを付け、`0` はそのまま表示する。取得できない値は `Not set` とし、上限を推測で補わない。
- 取得中は `Capacity` の上限の位置にだけ `Loading...` を出し、上限以外の項目は表示したままにする。取得中は古い上限を表示しない。
- 保持する結果は Foundry ごとにメモリだけに持ち、ファイルには保存しない。同じ Foundry の他のデプロイでは Azure を呼ばない。
- 起動時と、Foundry の切り替え、テナントの変更、ログアウト後の再ログインによる読み込み、画面の読み込みでは、保持状態を破棄する。対象 Foundry が確定したらデプロイ一覧と上限情報の取得を同時に開始し、一覧は上限の完了を待たずに表示する。
- 破棄前の取得が後から完了しても、変更後の保持状態と画面へ反映しない。
- 一覧の更新、デプロイモデルの追加・設定変更・削除では、保持した結果を取り直さない。
- 明細の表示でファイルは変更しない。
