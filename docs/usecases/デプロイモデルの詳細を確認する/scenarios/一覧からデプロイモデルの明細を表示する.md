# 一覧からデプロイモデルの明細を表示する

- 種別: 主成功
- UI確認: 要

## 開始条件

Home画面に選択中の Foundry のモデル一覧が表示され、対象モデルが1件以上存在する。取得・更新・切り替え処理は実行中でない。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 左側の一覧で対象デプロイの行を押す。 | 行を選択状態にし、右側の `Details` に、Azure から取得済みの一覧の内容でデプロイ名と `Capacity` の上限以外の項目を即時表示する。Azure は呼ばない。左の一覧と Foundry の選択は維持する。`Capacity` の上限は「明細の容量上限を表示する」で表示する。 |
| 2 | 同じデプロイの行または別のデプロイの行を押す。 | 指定したデプロイの明細に切り替えて即時表示する。 |

## 受け入れ条件

- Home画面のモデル領域を一つの外枠で囲み、左に一覧、右に明細を表示する。一覧と明細の幅は「デプロイモデルを閲覧する」の受け入れ条件に従う。間に境界線を置き、同じ高さの見出しを左は `Deployments`、右は `Details` とする。
- `Deployed Models` は Foundry のラベルと同じ文字サイズ・太さで、一覧と明細の外枠の上に表示する。見出し・更新ボタン・件数・取得日時を同じ行に左寄せでこの順に配置し、行全体の枠と背景を設けず、更新ボタンにも通常状態の枠と背景を設けない。一覧の列は「デプロイモデルを閲覧する」の共通の受け入れ条件に従い、選択行を青で強調する。
- 一覧は行のどこを押しても選択できる。デプロイ名はキーボードでも操作できるボタンとする。初期表示ではモデルを選択せず、右側の明細内容は空とする。
- 画面内の項目名・操作名・状態は英語で表示し、操作方法の補足説明は表示しない。
- 明細の見出しにデプロイ名を表示する。項目表に `Model`、`Version`、`SKU`、`Capacity`、`Provisioning state`、`Upgrade policy` を表示する。`Capacity` の現在値と単位は、一覧の取得結果から表示する。
- `Upgrade policy` の表示名は `OnceNewDefaultVersionAvailable` を `Upgrade to new default`、`OnceCurrentVersionExpired` を `Upgrade on retirement`、`NoAutoUpgrade` を `No automatic upgrade` とする。内部値は変更しない。未設定は `Not set`、未知の値は内部値をそのまま表示する。その他の値が返されない項目も `Not set` と表示する。
- 明細には取得日時を表示しない。取得日時は一覧の見出し行の `Last fetched` だけとする。
- 明細は一覧の取得結果から表示し、選択のたびに Azure から取得し直さない。同じデプロイを選んだ場合も同じ表示とする。
- 明細の表示でファイルは変更しない。保存ファイルは Foundry 一覧・選択・取得日時だけを持ち、デプロイ一覧と明細は保存しない。
- Foundry またはテナントが変わる場合、および一覧が更新された場合は、明細の選択と表示を破棄し、変更前の明細を表示しない。再起動後も明細は選択されない。
