# 容量上限の取得に失敗する

- 種別: 拡張
- UI確認: 要

## 分岐条件

デプロイ一覧と並行して開始したモデル定義一覧または共有クォータ一覧の取得に失敗する。デプロイの選択前に失敗した場合と、選択後に失敗した場合を含む。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | デプロイの行を押す。 | 上限以外の項目を即時表示する。取得中なら `Capacity` の上限の位置に `Loading...` を出し、既に失敗している場合はその失敗を明細に表示する。行選択では取得を開始しない。 |
| 2 | 失敗の表示を確認する。 | `Capacity` の上限の位置に `Not set` を表示し、明細内にエラーコード `DEPLOYMENT_DETAIL_FAILED` と理由、`Retry` を表示する。上限以外の項目と左の一覧は維持する。 |
| 3 | `Retry` を押す。 | 上限の取得だけをやり直す。 |

## 受け入れ条件

- 取得失敗の状態と理由はメモリに保持し、選択前に失敗した場合も明細を開いた時点で表示する。`Retry` で上限情報だけを取得し直す。再び失敗した場合も同じ表示とし、成功した場合はエラーと `Retry` を消して上限を表示する。
- 上限の取得失敗でデプロイ一覧の表示を止めない。
- 失敗時も、上限以外の項目、左の一覧、Foundry の選択は変更しない。
- 失敗と再試行でファイルは変更しない。
