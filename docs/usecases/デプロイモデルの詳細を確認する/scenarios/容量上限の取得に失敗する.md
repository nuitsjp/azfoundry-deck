# 容量上限の取得に失敗する

- 種別: 拡張
- UI確認: 要

## 分岐条件

「明細の容量上限を表示する」の初回の取得で、モデル定義一覧または共有クォータ一覧の取得に失敗する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | その Foundry で最初にデプロイの行を押す。 | 上限以外の項目を即時表示し、`Capacity` の上限の位置に `Loading...` を出して上限を取得する。 |
| 2 | 失敗の表示を確認する。 | `Capacity` の上限の位置に `Not set` を表示し、明細内にエラーコード `DEPLOYMENT_DETAIL_FAILED` と理由、`Retry` を表示する。上限以外の項目と左の一覧は維持し、操作を再び受け付ける。 |
| 3 | `Retry` を押す。 | 上限の取得だけをやり直す。 |

## 受け入れ条件

- 失敗した取得結果は保持しない。`Retry` で取得し直す。再び失敗した場合も同じ表示とし、成功した場合はエラーと `Retry` を消して上限を表示する。
- 失敗時も、上限以外の項目、左の一覧、Foundry の選択は変更しない。
- 失敗と再試行でファイルは変更しない。
