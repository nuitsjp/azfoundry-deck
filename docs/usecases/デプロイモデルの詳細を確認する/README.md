# デプロイモデルの詳細を確認する

## 主アクター

Azure にログイン済みの Foundry 運用者。

## 目的

一覧から選んだデプロイモデルの設定と状態を確認する。

## 前提

Home画面で Foundry が選択され、そのデプロイ済みモデル一覧が Azure から取得されて表示されている。

## 共通の受け入れ条件

- 選択中の Foundry に属する、指定したデプロイモデルの明細を表示する。
- 明細の項目は参照専用とする。設定の変更は、明細見出しの Edit deployment から「デプロイモデルの設定を変更する」で行う。
- 明細はファイルに保存しない。保存ファイルは Foundry 一覧・選択・取得日時だけを持ち、明細の表示で変更しない。
