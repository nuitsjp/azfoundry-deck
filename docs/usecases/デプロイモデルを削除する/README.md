# デプロイモデルを削除する

## 主アクター

Azure にログイン済みの Foundry 運用者。

## 目的

Home画面で選択中の Foundry から、指定したデプロイモデルを Azure 上で削除し、一覧から取り除く。

## 前提

Home画面で Foundry が選択され、そのデプロイ済みモデル一覧が表示されている。

## 共通の受け入れ条件

- 削除対象は、選択中の Foundry に属するデプロイモデル1件とする。
- 削除は元に戻せないため、実行前に確認ダイアログで対象のデプロイ名を示し、利用者の確認を必須とする。
- Azure 上の削除が成功するまで、一覧と保存済みファイルは変更しない。
- 削除の失敗時は、一覧を変更せず、エラーコードと理由を表示する。
