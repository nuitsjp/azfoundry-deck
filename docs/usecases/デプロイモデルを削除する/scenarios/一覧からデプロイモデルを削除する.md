# 一覧からデプロイモデルを削除する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が、Foundry 一覧とデプロイ済みモデルを表示した Home画面で、一覧からデプロイを選んで右側の明細を表示し、明細下部の削除ボタンを押す。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 削除したいモデルを一覧から選び、明細の下部にある削除ボタンを押す。 | 確認ダイアログを開き、選択中の Foundry 名と削除対象のデプロイ名、元に戻せないことを表示する。 |
| 2 | 内容を確認し、「削除」を押す。 | 「Deleting deployment」の進捗モーダルを開き、Azure に削除を依頼して、完了まで待つ。 |
| 3 | 削除後のデプロイ済みモデルを確認する。 | 削除完了後に、選択中の Foundry のデプロイ済みモデルを Azure から取得し直して保存し、保存成功後に進捗モーダルを閉じる。モデル一覧・モデル件数・最終取得日時を更新する。 |

## 受け入れ条件

- 確認ダイアログで「キャンセル」を押した場合は、Azure への操作も画面の変更も行わない。
- 削除は選択中の Foundry の指定したデプロイ1件だけを対象とし、ほかのデプロイ・Foundry・保存済みファイルは変更しない。
- 削除の完了後は、削除前の一覧からの除外ではなく、Azure から取得し直した結果で選択中の Foundry のモデルファイルと表示を置き換える。
- 削除中は進捗モーダルを Escape や外側クリックで閉じない。
- 削除の成功後に明細を表示していた場合、その明細を破棄する。
- 失敗時はモーダルを閉じ、削除前の一覧を維持して、エラーコード `DEPLOYMENT_DELETE_FAILED` と理由、再試行できる操作を表示する。権限不足もこの失敗に含め、理由に表示する。
- 再起動後や別の Foundry へ変更して戻った場合も、削除後のモデル一覧を表示する。
