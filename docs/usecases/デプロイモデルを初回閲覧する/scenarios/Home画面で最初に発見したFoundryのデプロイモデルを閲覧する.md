# Home画面で最初に発見したFoundryのデプロイモデルを閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が Home画面を初めて表示する。参照可能な Foundry が1件以上存在し、一覧取得とファイル保存が成功する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | ログイン済みの状態で Home画面を初めて表示する。 | Foundry の一覧取得を開始する。相互に依存しない取得処理を並列に実行する。 |
| 2 | 取得結果を待つ。 | 最初に発見した Foundry を選択し、その Foundry の全デプロイ済みモデルの取得を開始する。残りの Foundry の一覧取得も継続する。 |
| 3 | Home画面で取得結果を確認する。 | Foundry の一覧をプルダウンに表示し、最初に発見した Foundry を選択状態にする。その Foundry の全デプロイ済みモデルを一覧表示する。Foundry の一覧、選択済みの Foundry、選択された Foundry の全デプロイ済みモデルをファイルに保存する。 |
| 4 | Foundry のプルダウンを開く。 | 取得したすべての Foundry を、各項目の全文が読める状態で表示する。表示形式は「名称（サブスクリプション名 - リソースグループ名）」とする。 |
| 5 | プルダウンを閉じ、選択済みの Foundry にマウスを合わせる。 | 選択状態の表示は幅に応じて末尾を省略し、マウスオーバー時には表示文字列の全文をツールチップに表示する。 |

## 受け入れ条件

- Foundry のプルダウンとデプロイ済みモデルの一覧が Home画面に表示される。
- 相互に依存しない Foundry の取得処理が並列に実行される。
- 最初に発見した Foundry のモデル取得は、すべての Foundry の取得完了を待たずに開始される。
- 後から別の Foundry が見つかっても、初期選択は変更されない。
- 取得完了後、Foundry の一覧には参照可能なすべての Foundry が含まれる。
- 選択された Foundry のモデル一覧には、その Foundry のすべてのデプロイ済みモデルが含まれる。
- モデル一覧にはデプロイ名・モデル名・バージョンを表示する。
- Foundry の一覧、選択済みの Foundry、選択された Foundry の全デプロイ済みモデルがファイルに保存され、画面の内容と一致する。
- プルダウンの各項目は「名称（サブスクリプション名 - リソースグループ名）」で表示される。
- プルダウンを開いた状態では、すべての項目の全文を確認できる。
- 選択状態では幅に応じて省略表示され、マウスオーバーで全文を確認できる。
