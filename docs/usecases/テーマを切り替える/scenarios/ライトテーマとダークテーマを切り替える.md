# ライトテーマとダークテーマを切り替える

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者がアプリを起動し、設定ファイルが存在しない初期状態（ダークテーマ）で画面（ログインモーダルまたは Home画面）を表示している。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | ヘッダー右側にあるテーマ切り替えボタンにマウスを合わせる。 | ライトテーマへの切り替えを示すツールチップを表示する。 |
| 2 | テーマ切り替えボタンを押す。 | データフォルダーの `settings.json` にライトテーマを保存し、アプリ全体の配色をライトテーマへ切り替える。ボタンのアイコン表示とツールチップをダークテーマへの切り替え案内に更新する。 |
| 3 | ライトテーマのまま Home画面の閲覧やモーダル表示（追加・設定変更・進捗など）を確認する。 | すべての領域でライトテーマに応じた背景色・文字色・境界線・選択行のハイライトを表示する。 |
| 4 | ページを再読み込みする（または同じデータフォルダーでアプリを再起動する）。 | 起動時に `settings.json` を読み込み、ライトテーマのまま画面を表示する。 |
| 5 | 再度テーマ切り替えボタンを押す。 | `settings.json` にダークテーマを保存し、アプリ全体の配色をダークテーマへ戻す。 |

## 受け入れ条件

- 切り替え操作で設定ファイルの保存が成功すると、ページ遷移を挟まず即座に新しいテーマが画面全体へ反映される。
- テーマを切り替えても、ログイン状態、選択中のテナントや Foundry、表示中のデプロイ一覧・明細・入力中の値は失われない。
- 設定ファイルの保存に失敗した場合はテーマを切り替えず元のテーマを維持し、エラーコード（`THEME_SAVE_FAILED`）と理由を表示する。
- 起動時に設定ファイルの読み込みや形式の検証に失敗した場合は、画面操作を止めずに初期テーマのダークテーマで表示を続け、エラーコード（`THEME_LOAD_FAILED`）と理由を表示する。
- ログアウトを実行しても `settings.json` は削除されず、選択中のテーマ設定を維持する。
