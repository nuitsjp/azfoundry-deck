# ライトテーマとダークテーマを切り替える

- 種別: 主成功
- UI確認: 要

## 開始条件

利用者がアプリを起動し、初期状態のダークテーマで画面（ログインモーダルまたは Home画面）を表示している。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | ヘッダー右側にあるテーマ切り替えボタンにマウスを合わせる。 | ライトテーマへの切り替えを示すツールチップを表示する。 |
| 2 | テーマ切り替えボタンを押す。 | 即座にアプリ全体の配色をライトテーマへ切り替え、切り替え後の選択を保存する。ボタンのアイコン表示とツールチップをダークテーマへの切り替え案内に更新する。 |
| 3 | ライトテーマのまま Home画面の閲覧やモーダル表示（追加・設定変更・進捗など）を確認する。 | すべての領域でライトテーマに応じた背景色・文字色・境界線・選択行のハイライトを表示する。 |
| 4 | ページを再読み込みする（またはアプリを再起動する）。 | 保存された選択を読み込み、ライトテーマのまま画面を表示する。 |
| 5 | 再度テーマ切り替えボタンを押す。 | 即座にアプリ全体の配色をダークテーマへ戻し、選択を更新して保存する。 |

## 受け入れ条件

- ダークテーマからライトテーマ、ライトテーマからダークテーマへの切り替えが、ページ遷移や画面再読み込みを挟まず即座に反映される。
- テーマを切り替えても、ログイン状態、選択中のテナントや Foundry、表示中のデプロイ一覧・明細・入力中の値は失われない。
- ブラウザーのローカル保存領域が利用できない場合でも、画面のテーマ切り替え自体はエラーを出さず動作する（再起動後の復元のみ行わない）。
- ログアウトを実行しても、選択中のテーマ設定はリセットされずに維持される。
