# テーマを切り替える

## 主アクター

Foundry の運用者。

## 目的

画面の表示テーマをダークテーマとライトテーマで切り替え、利用環境や好みに合わせた配色でアプリを操作できるようにする。

## 前提

アプリを起動している（ログイン前・ログイン後のいずれの状態でもよい）。

## 共通の受け入れ条件

- アプリ全体の共通ヘッダー右側に、現在のテーマと反対のテーマへ切り替えるボタンを常に表示する。ログイン済み時はテナントプルダウンの左隣に、未ログイン時はウィンドウ操作ボタンの左隣（サーバーモード時はヘッダー右端）に配置し、マウスオーバー時に切り替え先のテーマを示すツールチップを表示する。
- アプリ起動時の初期テーマはダークテーマとする。設定ファイル（`settings.json`）に保存されたテーマがある場合は起動時に復元し、明示的に切り替えた選択は設定ファイルへ保存して再起動後も維持する。
- OS のシステム配色設定への自動追従は行わない。
- ライトテーマとダークテーマの切り替えでは、画面全体（ヘッダー、Home画面、各種モーダル、テーブル、選択ハイライト、境界線、バッジ、エラー表示、スクロール領域を含む）の配色を切り替え後のテーマに即座に統一し、文字・アイコン・境界線に十分なコントラストを保つ。
- テーマ設定はアカウントやテナントに紐づかないアプリ共通の設定とし、ログアウトやテナント変更を行っても選択中のテーマを維持する。
- テーマの切り替えは Azure への通信や認証・Foundry 状態ファイルの変更を伴わず、表示中の入力内容・取得済み一覧・選択状態を変更しない。
