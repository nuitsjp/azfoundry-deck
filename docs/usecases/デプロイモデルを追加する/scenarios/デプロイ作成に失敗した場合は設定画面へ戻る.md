# デプロイ作成に失敗した場合は設定画面へ戻る

- 種別: 拡張
- UI確認: 要

## 分岐条件

[新規デプロイモデルを追加する](新規デプロイモデルを追加する.md) の手順2で「Deploy」を押した後、デプロイ名の重複やクォータ不足などにより Azure 側で作成に失敗した場合。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 2a-1 | （手順2で「Deploy」を押した状態） | 前面の進捗モーダルで作成失敗を検知し、進捗モーダルを閉じてデプロイ作成モーダルへ戻る。デプロイ作成モーダル内に入力済みの設定値（選択モデル、Deployment name、Version、Capacity 等）をすべて保持したまま、上部にエラー理由（名称重複、クォータ不足等）を表示する。 |
| 2a-2 | エラー理由を確認し、Deployment name や Capacity などの設定を修正して再度「Deploy」を押す。 | 再度前面に進捗モーダルを表示してデプロイ作成を再試行し、成功した場合は主成功系列の手順3へ合流する。 |

## 受け入れ条件

- デプロイ作成失敗時、デプロイ作成モーダルを閉じずに維持し、前面の進捗モーダルのみを閉じる。
- 選択中のモデル、Deployment name、Version、Capacity などの入力値は失われずそのまま残る。
- モーダル内にエラー原因（Azure から返された名称重複、クォータ不足などの理由）を分かりやすく表示する。
- 設定を修正して再試行（「Deploy」）できる。
- 修正を諦めて「Cancel」または「×」を押した場合はデプロイ作成モーダルを閉じ、作成前の一覧を維持する。
