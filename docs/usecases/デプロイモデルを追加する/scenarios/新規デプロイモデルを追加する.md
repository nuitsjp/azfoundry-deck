# 新規デプロイモデルを追加する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が、Foundry 一覧とデプロイ済みモデルを表示した Home画面で、「Add deployment」ボタンを押す。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | デプロイ済みモデル一覧の見出し右にある「Add deployment」ボタンを押す。 | デプロイ作成モーダルを開き、Azure から利用可能なモデルカタログとクォータ情報を取得する間のプログレスを表示する。取得完了後、左側にモデル検索・フィルター（Publisher、Deployment option、Tasks）とモデル一覧、右側にデプロイ設定入力欄を表示する。初期状態で先頭のモデルを選択し、Deployment name にそのモデル名を初期設定する。 |
| 2 | 左側で追加したいモデルを選び、必要に応じて右側で設定（Deployment name、Version、SKU、Capacity 等）を調整して「Deploy」を押す。 | デプロイ作成モーダルを開いたまま、その前面に進捗モーダル（Step: Deploy）を重ねて表示し、Azure にデプロイ作成を依頼して完了まで待つ。 |
| 3 | 作成完了後のデプロイ済みモデルを確認する。 | 作成完了後に選択中 Foundry のデプロイ済みモデルを Azure から取得し直して保存し、進捗モーダルとデプロイ作成モーダルの両方を閉じる。モデル一覧・件数・最終取得日時を更新し、新規追加されたモデルを表示する。 |

## 受け入れ条件

- モーダルで「Cancel」または「×」を押した場合は、Azure への操作も画面の変更も行わない。
- モデル選択時、右ペインの Deployment name には選択したモデル名がデフォルトで自動入力され、テキストボックスで直接編集できる。
- モデルカタログの Publisher、Deployment option、Tasks（Chat, Reasoning, Embeddings, Multimodal 等）のフィルターでモデル一覧をリアルタイムに絞り込める。
- Standard モデル選択時は Capacity の割り当て可能上限（利用可能クォータ）を明示し、詳細画面と揃えた形式（`現在値 / 最大値 TPM`）で表示する。初期値は上限の 50% とし、数値テキストボックスでの直接入力とスライダーの両方で 1,000 単位で調整でき、双方が連動する。
- Pay-as-you-go モデル選択時は TPM クォータ入力を行わず、従量課金レート情報を表示する。
- 必須項目（Deployment name 等）の未入力または不正値がある場合は作成を実行できない。
- デプロイ実行時は確認ダイアログを表示せず、デプロイ作成モーダルの前面に進捗モーダル（Step: Deploy）を表示する。進捗モーダルは Escape や外側クリックで閉じない。
- デプロイの完了後は、作成前の一覧への手動追加ではなく、Azure から取得し直した結果で選択中 Foundry のモデルファイルと表示を置き換える。
- 再起動後や別の Foundry へ変更して戻った場合も、追加後のモデル一覧を表示する。
