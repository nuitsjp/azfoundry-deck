# デプロイモデルを追加する

## 主アクター

Azure にログイン済みの Foundry 運用者。

## 目的

Home画面で選択中の Foundry に新しいデプロイモデルを作成（デプロイ）し、一覧へ反映する。

## 前提

Home画面で Foundry が選択され、そのデプロイ済みモデル一覧が表示されている。

## 共通の受け入れ条件

- 追加対象は、選択中の Foundry に属するデプロイモデルとする。
- 作成が Azure 上で完了するまで、一覧と保存済みファイルは変更しない。
- 作成成功後は、Azure からデプロイ済みモデルを取得し直して保存し、一覧・件数・最終取得日時を最新化する。
- 作成失敗時は、一覧を変更せず、エラーコードと理由を表示し、再試行できるようにする。
