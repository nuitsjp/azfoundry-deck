# ヘッダーのユーザーアイコンからログアウトする

- 種別: 主成功
- UI確認: 要

## 開始条件
ログイン済みで、Home を表示している。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | ヘッダー右のユーザーアイコンを押す | アカウント名と「ログアウト」だけのメニューを表示する |
| 2 | 「ログアウト」を選ぶ | 保存済みのアカウント識別情報、Azure SDK の永続キャッシュ上のトークン、メモリ上のログイン状態を、すべて削除する |
| 3 | （操作なし） | ヘッダー右のテナント名とユーザーアイコンを消し、閉じられないログインモーダルを表示する |

## 受け入れ条件
- 手順2の後、資格情報マネージャーにこのアプリのアカウント識別情報が存在せず、Azure SDK の永続キャッシュ（`%LOCALAPPDATA%\.IdentityService` 配下の `azfoundrydeck` 系のファイル）も存在しない。
- ログアウトの後にアプリを再起動しても、自動ログインされず、通常のログインモーダルが出る。
- 手順2の削除のいずれかに失敗した場合は、ログアウト済みにならず、ログイン済みのまま、メニューを閉じずにエラーのコードと理由を表示する。再度「ログアウト」を押せる。
- ログアウトの確認ダイアログは表示しない。
