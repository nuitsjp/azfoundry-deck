# ヘッダーのユーザーアイコンからログアウトする

- 種別: 主成功
- UI確認: 要

## 開始条件
ログイン済みで Home を表示している。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | ユーザーアイコンを押す | アカウント名と「ログアウト」だけのメニューを表示する。 |
| 2 | 「ログアウト」を選ぶ | このアプリの認証記録、永続トークンキャッシュ、テナント一覧、選択テナント、すべてのアカウント・テナントの Foundry・モデル保存データを削除する。メモリ上の認証・テナント・閲覧状態も破棄する。 |
| 3 | （操作なし） | テナントプルダウン、ユーザーアイコン、閲覧結果を消し、閉じられないログインモーダルを表示する。 |

## 受け入れ条件
- ログアウト成功後は、上記の保存情報とメモリ上の状態が残らない。
- 再起動しても自動ログインされない。
- 次のサインインで ARM からテナント一覧を取得し直す。
- 削除のいずれかに失敗した場合は、ログアウト済みにならず、メニュー内にエラーのコードと理由を表示する。再度「ログアウト」を押せる。
- 確認ダイアログは表示しない。
- 他のアプリの認証情報・トークンには触れない。
