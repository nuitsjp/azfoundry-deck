# Azureからログアウトする

## 主アクター
Azure 上の Microsoft Foundry を管理する運用者（Azure アカウントを持つ個人）

## 目的
このアプリの Azure ログイン状態と、保存した認証・テナント・閲覧情報をすべて破棄する。

## 前提
- ログイン済みで、ヘッダー右側にテナントプルダウンとユーザーアイコンが表示されている。

## 共通の受け入れ条件
- パスワードやトークンを画面・ログへ平文で出さない。
