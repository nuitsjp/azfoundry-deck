# Azureからログアウトする

## 主アクター
Azure 上の Microsoft Foundry を管理する運用者（Azure アカウントを持つ個人）

## 目的
このアプリの Azure ログイン状態と、保存したログイン情報を破棄し、次回起動時に自動でログインされない状態にする。

## 前提
- アプリがログイン済みである（ヘッダー右にテナント名とユーザーアイコンが出ている）。

## 共通の受け入れ条件
- パスワードやトークンを画面・ログへ平文で出さない。
