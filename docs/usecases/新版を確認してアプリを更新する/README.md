# 新版を確認してアプリを更新する

## 主アクター
Windowsでアプリを利用する人。

## 目的
起動のたびに GitHub Releases の新版をバックグラウンドで確認して取得・検証しておき、利用者が選んだときに新版へ更新して再起動する。

## 前提
- アプリはインストーラーで導入されている。
- GitHub Releases の最新リリース（下書きとプレリリースを除く）に、インストーラーと、その版・サイズ・ハッシュを記載して署名した `update.json` が置かれている。

## 共通の受け入れ条件
- 新版の確認・取得・検証は、ログイン、Foundry とデプロイモデルの閲覧・操作、ウィンドウの操作を止めない。
- `update.json` の署名、対象アプリと CPU、インストーラーのサイズとハッシュのどれかが一致しない新版は、取得済みとして扱わない。
- ログイン状態、選択テナント、保存済みの Foundry 一覧と選択は、更新の前後で変わらない。
