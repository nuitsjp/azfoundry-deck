# デプロイモデルを閲覧する

## 主アクター

Foundry の運用者。

## 目的

Home画面で Foundry 一覧と選択された Foundry のデプロイ済みモデルを確認する。

## 前提

Azure にログイン済みである。

## 共通の受け入れ条件

- Home画面に Foundry のプルダウンと、選択された Foundry のすべてのデプロイ済みモデルを表示する。
- モデル一覧には `Deployment`・`Model`・`Version`・`Capacity` の4列を表示する。
- プルダウンの表示形式は「名称 (サブスクリプション名 - リソースグループ名)」とする。
- プルダウンを開いたときは、すべての Foundry の各項目を全文が読める状態で表示する。
- プルダウンを閉じたときは、選択表示を幅に応じて末尾で省略し、マウスオーバー時に全文をツールチップで表示する。
- Foundry のプルダウンの行の下、見出し `Deployed Models` の上に、選択中の Foundry の接続情報として `Azure OpenAI Endpoint` と `API key` を、この順に1行で横に並べて表示する。各項目の値の右にコピーボタンを置く。接続情報の行の上下の余白は同程度とする。
- `API key` は Key1 を対象とし、伏せ字と末尾4文字で表示する。全文を画面に表示する操作は設けない。コピーボタンはエンドポイントまたはキーの全文をクリップボードへ書き込み、ボタンの表示を約2秒間 `Copied` に変える。
- 接続情報は保存せず、メモリだけに持つ。取得・保持・破棄の時点は容量上限情報と同じとし、選択中の Foundry 以外の接続情報を表示しない。
- Foundry のプルダウンの行と接続情報の行の間に、選択中の Foundry のサブスクリプションの行を表示する。左に `Subscription ID` と値（Foundry のリソース ID から取り出したサブスクリプション ID）とコピーボタン、その右に `Month-to-date cost` と利用金額を、この順に1行で横に並べる。プルダウンの行、サブスクリプションの行、接続情報の行の縦の間隔は同程度とする。Foundry が選択されていない場合はこの行を表示しない。
- `Subscription ID` のコピーボタンは、接続情報のコピーボタンと同じくサブスクリプション ID の全文をクリップボードへ書き込み、ボタンの表示を約2秒間 `Copied` に変える。
- `Month-to-date cost` は、Azure Cost Management から取得した選択中の Foundry のサブスクリプションの当月（月初から当日まで）の実コスト（ActualCost）の合計とする。金額は Azure Cost Management が返す税抜きの請求通貨の値とし、為替換算は行わない。請求通貨が日本円の場合は `¥` と、1円未満を四捨五入した3桁区切りの整数（例: `¥12,345`）で表示する。日本円以外の場合は、小数2桁の3桁区切りの数値と通貨コード（例: `1,234.56 USD`）で表示する。
- 利用金額はファイルに保存せず、サブスクリプション ID ごとにメモリだけに持つ。Foundry の選択が確定したときに、そのサブスクリプションの利用金額を保持していなければ、デプロイ済みモデル、容量上限情報、接続情報と並行して取得する。保持済みのサブスクリプションの Foundry に変更した場合は取得し直さない。Home画面の閲覧（アプリケーションの起動を含む）、テナントの変更、ログアウトの時点で保持した利用金額をすべて破棄する。「Refresh models」の操作では、選択中の Foundry のサブスクリプションの利用金額を取得し直す。
- 利用金額の取得中は、金額の位置に回転表示と `Loading...` を表示する。デプロイ済みモデルの一覧の表示は利用金額の取得完了を待たず、取得完了時に利用者の追加操作なしで金額を表示する。
- 利用金額の取得に失敗した場合（権限不足、Azure Cost Management に対応しないサブスクリプション、要求回数の制限を含む）は、金額の位置に `COST_LOAD_FAILED: 理由` を1行の小さな赤字で表示し、バナーは出さない。再試行のボタンは置かず、「Refresh models」の操作で取得し直す。失敗はデプロイ済みモデルの一覧・接続情報の表示に影響させない。
- Foundry 一覧の最終取得日時は、プルダウン右の更新ボタンの右隣に、ボタンと同じ高さで表示する。
- モデル一覧の上に見出し `Deployed Models` を表示し、見出しの右に更新ボタン、モデル件数、選択中の Foundry のモデルの最終取得日時を、この順で左寄せに表示する。取得日時は `Last fetched` の表記で表示する。
- 最終取得日時は、直近に Azure から取得が完了した時刻をローカル時刻の YYYY-MM-DD HH:mm 形式で表示する。
- デプロイ済みモデルの一覧は保存せず、Home画面を表示するたびに Azure から取得する。取得した一覧と取得日時はメモリだけに持つ。
- 状態ファイルには Foundry 一覧・選択済み Foundry・Foundry 一覧の最終取得日時（`foundries`・`selectedFoundryId`・`foundriesFetchedAt`）だけを保存する。デプロイ済みモデルの一覧のファイルや `foundry-models` ディレクトリは作らない。
- 保存済みの Foundry 一覧・選択済み Foundry がある場合は、Foundry 一覧を取得せず、選択済み Foundry のデプロイ済みモデル、容量上限情報、接続情報、サブスクリプションの利用金額を並行して Azure から取得する。
