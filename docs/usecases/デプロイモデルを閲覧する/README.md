# デプロイモデルを閲覧する

## 主アクター

Foundry の運用者。

## 目的

Home画面で Foundry 一覧と選択された Foundry のデプロイ済みモデルを確認する。

## 前提

Azure にログイン済みである。

## 共通の受け入れ条件

- Home画面に Foundry のプルダウンと、選択された Foundry のすべてのデプロイ済みモデルを表示する。
- モデル一覧にはデプロイ名・モデル名・バージョンを表示する。
- プルダウンの表示形式は「名称（サブスクリプション名 - リソースグループ名）」とする。
- プルダウンを開いたときは、すべての Foundry の各項目を全文が読める状態で表示する。
- プルダウンを閉じたときは、選択表示を幅に応じて末尾で省略し、マウスオーバー時に全文をツールチップで表示する。
