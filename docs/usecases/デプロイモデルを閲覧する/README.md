# デプロイモデルを閲覧する

## 主アクター

Foundry の運用者。

## 目的

Home画面で Foundry 一覧と選択された Foundry のデプロイ済みモデルを確認する。

## 前提

Azure にログイン済みである。

## 共通の受け入れ条件

- Home画面に Foundry のプルダウンと、選択された Foundry のすべてのデプロイ済みモデルを表示する。
- モデル一覧にはデプロイ名・モデル名・バージョンを表示する。
- プルダウンの表示形式は「名称（サブスクリプション名 - リソースグループ名）」とする。
- プルダウンを開いたときは、すべての Foundry の各項目を全文が読める状態で表示する。
- プルダウンを閉じたときは、選択表示を幅に応じて末尾で省略し、マウスオーバー時に全文をツールチップで表示する。
- 現在と同じ Foundry を選択した場合はプルダウンを閉じるだけとし、モデル取得・進捗表示・保存を行わない。
- Foundry のプルダウンの右に「Foundry一覧を更新」ボタン（マウスオーバー時にツールチップで名称を表示するアイコンボタン）を置き、プルダウンの下に Foundry 一覧の最終取得日時を表示する。
- モデル一覧の上に見出し「デプロイ済みモデル」を表示し、見出しの右に「モデルを更新」ボタン（マウスオーバー時にツールチップで名称を表示するアイコンボタン）、その右にモデル件数と選択中の Foundry のモデルの最終取得日時を表示する。
- 最終取得日時は、Azure からの取得が完了した時刻をローカル時刻の YYYY-MM-DD HH:mm 形式で表示する。保存済みファイルから表示する場合は、保存された取得日時を表示する。
- Foundry 一覧またはモデルの更新中は、閉じるボタン・Escape・モーダル外クリックで進捗モーダルを閉じず、Foundry の変更と更新操作を受け付けない。
