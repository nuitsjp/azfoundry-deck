# Foundryが存在しない状態で初回閲覧する

- 種別: 拡張
- UI確認: 要

## 分岐条件
ログイン済みの利用者が Home画面を表示し、保存済みの Foundry 一覧・選択済み Foundry・モデル一覧が存在しない。サブスクリプションの検索と Foundry の取得は成功したが、参照可能な Foundry が1件もない。ファイル保存が成功する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | ログイン済みの状態で Home画面を初めて表示する | 「デプロイモデルを取得しています」という進捗モーダルを開き、サブスクリプションの検索と Foundry の取得を行う。進捗は主成功と同じ形式で表示する。 |
| 2 | モーダルで取得の進捗を確認する | すべてのサブスクリプションの取得が完了し、Foundry が0件であることを確認する。モデルの取得は行わない。 |
| 3 | 取得と保存の完了を確認する | Foundry が0件であることと取得日時をファイルに保存する。保存成功後にモーダルを自動で閉じ、「参照可能な Foundry がありません」を表示する。 |

## 受け入れ条件
- 参照可能な Foundry が0件の場合を、エラーとして扱わない。`FOUNDRY_LOAD_FAILED` を表示しない。
- 進捗モーダルは、Foundry の取得からファイル保存の完了まで主成功と同じ形式で表示し、モデル取得の進捗は表示しない。
- Foundry が0件であること、Foundry 一覧の最終取得日時を状態ファイルに保存し、画面の内容と一致させる。
- Home画面には、Foundry のプルダウンとデプロイ済みモデルの一覧に代えて、「参照可能な Foundry がありません」という案内を表示する。案内はエラー表示ではなく、情報として表示する。
- 「Foundry一覧を更新」ボタンと Foundry 一覧の最終取得日時は表示し、更新を実行できる。
- アプリケーションを再起動した場合は、保存済みの状態から同じ案内を表示し、Azure から取得し直さない。
