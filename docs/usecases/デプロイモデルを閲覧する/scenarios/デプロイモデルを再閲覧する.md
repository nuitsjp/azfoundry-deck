# デプロイモデルを再閲覧する

- 種別: 拡張
- UI確認: 要

## 分岐条件

ログイン済みの利用者が Home画面を表示し、サブスクリプション検索を開始する前に、保存済みの Foundry 一覧・選択済み Foundry・モデル一覧が存在し、ファイルの読み込みに成功する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | 保存済みのデータがある状態で Home画面を表示する。 | ファイルから Foundry 一覧・選択済み Foundry・モデル一覧を読み込む。 |
| 2 | Foundry とデプロイ済みモデルを確認する。 | 保存された Foundry の選択を維持し、その Foundry の保存されたすべてのデプロイ済みモデルを表示する。 |
| 3 | Foundry のプルダウンを開く。 | 保存されたすべての Foundry を、各項目の全文が読める状態で表示する。 |
| 4 | プルダウンを閉じ、選択済みの Foundry にマウスを合わせる。 | 選択状態の表示は幅に応じて末尾を省略し、マウスオーバー時には表示文字列の全文をツールチップに表示する。 |

## 受け入れ条件

- アプリケーションを再起動した場合も、保存済みファイルから Foundry 一覧・選択済み Foundry・モデル一覧を復元する。
- 復元した Foundry 一覧・選択済み Foundry・モデル一覧は保存内容と完全に一致する。
- 保存された Foundry の選択を維持し、最初の Foundry に選択を変更しない。
- サブスクリプション・Foundry・モデルの Azure からの取得を実行しない。
- 取得の進捗モーダルを表示しない。
- 読み込んだデータを再保存しない。
