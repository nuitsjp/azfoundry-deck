# デプロイモデルを閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が Home画面を表示し、保存済みの Foundry 一覧・選択済み Foundry が存在しない。参照可能な Foundry が1件以上存在する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | ログイン済みの状態で Home画面を初めて表示する。 | 「Loading deployments」という進捗モーダルを開き、Foundry 一覧の取得を開始する。「Foundries」を「Loading」、「Deployments」を「Waiting」で表示する。 |
| 2 | モーダルで取得の進捗を確認する。 | Foundry 一覧の取得後、「Foundries」を「Completed」と取得した Foundry の件数で表示する。一覧の最初の Foundry を選択し、その全デプロイ済みモデル、容量上限情報、接続情報（エンドポイントと API キー）の取得を並行して開始する。「Deployments」を「Loading」にし、選択先の名称と累積件数を表示する。 |
| 3 | 取得と保存の完了を確認する。 | 全モデルの取得後に「Deployments」を「Completed」にし、Foundry 一覧・選択済み Foundry・Foundry 一覧の最終取得日時をファイルに保存する。保存成功後にモーダルを自動で閉じ、Home画面に Foundry のプルダウンと選択先の全モデルを表示する。各行の `Capacity` は `現在値 / 上限 単位` とし、上限が取得中なら分母に回転表示と `Loading...` を表示する。プルダウンの下に `Azure OpenAI Endpoint` と `API key` を表示し、接続情報が取得中なら各値の位置に回転表示と `Loading...` を表示してコピーボタンを無効にする。 |
| 4 | Foundry のプルダウンを開く。 | 取得したすべての Foundry を、各項目の全文が読める状態で表示する。表示形式は「名称 (サブスクリプション名 - リソースグループ名)」とする。 |
| 5 | プルダウンを閉じ、選択済みの Foundry にマウスを合わせる。続けて `Azure OpenAI Endpoint` と `API key` のコピーボタンを順に押す。 | 選択状態の表示は幅に応じて末尾を省略し、マウスオーバー時には表示文字列の全文をツールチップに表示する。容量上限が取得中の場合は、取得が完了した時点で、利用者の追加操作なしに全行の `Capacity` を更新する。この更新はプルダウンやマウスの操作に依存しない。接続情報の取得完了時も同様に、`Azure OpenAI Endpoint` に全文、`API key` に伏せ字と末尾4文字を表示し、コピーボタンを有効にする。コピーボタンが押されると、押した項目の全文をクリップボードへ書き込み、そのボタンの表示を約2秒間 `Copied` に変える。`API key` の表示は伏せ字のまま変えない。 |

## 受け入れ条件

- 保存済みの Foundry 一覧・選択済み Foundry が存在しない場合に、Foundry 一覧とモデル一覧を Azure から取得する。
- 取得開始時から保存完了まで、進捗モーダルを表示する。
- 進捗モーダルは「Foundries」と「Deployments」の2行を、開いた時点から完了まで表示する。各行は「Waiting」「Loading」「Completed」を表示し、取得中の行には回転表示を付ける。モーダルの大きさは完了まで変えず、結果は各行の右側に表示する。経過時間は表示しない。
- 「Foundries」の完了時に、取得した Foundry の件数を表示する。
- Foundry 一覧は、参照可能なすべての Foundry を全ページ取得し、サブスクリプション名、Foundry 名の昇順に並べる。選択先のモデル一覧は全ページを取得し、選択先のすべてのデプロイ済みモデルを含める。
- 一覧の最初の Foundry を選択先とし、一覧の取得完了後にモデル取得を開始する。
- 「Deployments」に、選択した Foundry の名称と取得したモデルの累積件数を表示する。
- 処理中は閉じるボタン・Escape・モーダル外クリックでモーダルを閉じない。
- 状態ファイルには Foundry 一覧・選択済み Foundry・Foundry 一覧の最終取得日時だけを保存し、画面の内容と一致させる。デプロイ済みモデルの一覧は状態ファイルに保存せず、`foundry-models` ディレクトリも作らない。
- 一覧と選択先の全モデルの取得、および必要なファイル保存のすべてが成功した後に結果を確定する。
- 保存成功後はモーダルを自動で閉じ、Home画面に結果を表示する。
- 保存済みの Foundry 一覧・選択済み Foundry がある状態でアプリケーションを起動した場合は、保存された選択を維持して最初の Foundry に変更せず、Foundry 一覧を取得し直さない。選択済み Foundry のデプロイ済みモデルを、同じ形式の進捗モーダルを表示して Azure から取得し、取得日時を取得完了時刻に更新する。
- 一覧の `Capacity` は分子・分母・単位を一つのセル内で一行に表示する。数値の桁区切り、`0`、取得できない値の `Not set`、単位は `Details` と同じ表示とする。
- 分子と分母の表示領域は、それぞれ全行で共通の幅を持ち、値を右寄せにする。全行のスラッシュとその左右の位置をそろえ、単位はその右で左寄せにする。
- 上限の取得中は分母だけに回転表示と `Loading...` を中央揃えで表示し、現在値と単位は維持する。セル内のすべての要素は上下中央にそろえる。
- 上限の取得完了時に、利用者の追加操作なしに全行の `Capacity` を更新する。一覧と `Details` は同じ取得結果を使う。
- 上限の取得失敗時は一覧の分母を `Not set` とする。エラーと `Retry` は `Details` に表示する。
- 一覧を約60%、`Details` を約40%の幅で表示する。一覧の `Capacity` は折り返さず、`Details` の項目と操作も読める幅を確保する。
- `Azure OpenAI Endpoint` は選択中の Foundry の Azure OpenAI v1 API のベース URL（`https://<Foundry 名>.openai.azure.com/openai/v1` の形式で、末尾にスラッシュを付けない）を全文で表示し、コピーも同じ値とする。幅に収まらない場合は末尾を省略してマウスオーバー時に全文をツールチップで表示する。
- `API key` は Key1 を伏せ字と末尾4文字で表示し、全文を画面・ツールチップ・ログ・ファイルに出さない。
- コピーボタンは表示上の省略や伏せ字に関係なく全文をクリップボードへ書き込む。取得中はコピーボタンを無効にする。
- 接続情報の取得完了を待たず、デプロイ一覧の取得と保存の成功後に一覧を表示する。接続情報は状態ファイルに保存しない。
- `Capacity` のセルを含め、行のどこを押してもデプロイを選択できる。
- 容量上限情報の取得完了を待たず、デプロイ一覧の取得と保存の成功後に一覧を表示する。上限情報の保持・再試行・破棄と一覧・明細への反映は「デプロイモデルの詳細を確認する」の容量上限表示の既存規則に従う。
