# デプロイモデルを更新する

- 種別: 拡張
- UI確認: 要

## 分岐条件

ログイン済みの利用者が Foundry 一覧とデプロイ済みモデルを表示した Home画面で、「モデルを更新」ボタンを押す。選択中の Foundry のモデルの取得とファイルへの保存が成功する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | モデル一覧の見出しの右にある「モデルを更新」ボタンを押す。 | 「デプロイモデルを更新しています」という進捗モーダルを開き、選択中の Foundry のすべてのデプロイ済みモデルを Azure から取得する。 |
| 2 | モーダルで取得の進捗を確認する。 | 選択中の Foundry の名称、モデル取得の状態と累積件数を表示する。全モデルの取得後にファイルの保存状態を表示する。 |
| 3 | 更新後のデプロイ済みモデルを確認する。 | 取得したモデルを保存し、保存成功後に進捗モーダルを閉じて、モデル一覧・モデル件数・最終取得日時を更新する。 |

## 受け入れ条件

- 選択中の Foundry のデプロイ済みモデルを、保存済みのモデルファイルの有無にかかわらず Azure から全ページ取得する。
- サブスクリプション一覧と Foundry 一覧を再取得せず、サブスクリプション検索と Foundry 取得の進捗を表示しない。
- 進捗モーダルに選択中の Foundry の名称、モデル取得の「取得中」「完了」と累積件数、ファイル保存の「待機中」「保存中」「完了」を表示する。
- 取得した全モデルと最終取得日時で選択中の Foundry のモデルファイルを置き換え、状態ファイルの表示モデルも更新して、画面の内容と一致させる。
- ほかの Foundry のモデルファイルは変更しない。
- 保存が成功するまで、更新前のモデル表示を維持する。
- アプリケーションを再起動した場合や、別の Foundry へ変更して戻った場合も、更新後のモデルと最終取得日時を表示する。
