# デプロイモデルを初回閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が Home画面を表示し、保存済みの Foundry 一覧・選択済み Foundry・モデル一覧が存在しない。参照可能な Foundry が1件以上存在する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | ログイン済みの状態で Home画面を初めて表示する。 | 「デプロイモデルを取得しています」という進捗モーダルを開き、Foundry 一覧の取得を開始する。「Foundry一覧の取得」を「取得中」、「デプロイモデルの取得」を「待機中」で表示する。 |
| 2 | モーダルで取得の進捗を確認する。 | Foundry 一覧の取得後、「Foundry一覧の取得」を「完了」と取得した Foundry の件数で表示する。一覧の最初の Foundry を選択し、その全デプロイ済みモデルを取得する。「デプロイモデルの取得」を「取得中」にし、選択先の名称と累積件数を表示する。 |
| 3 | 取得と保存の完了を確認する。 | 全モデルの取得後に「デプロイモデルの取得」を「完了」にし、結果をファイルに保存する。保存成功後にモーダルを自動で閉じ、Home画面に Foundry のプルダウンと選択先の全モデルを表示する。 |
| 4 | Foundry のプルダウンを開く。 | 取得したすべての Foundry を、各項目の全文が読める状態で表示する。表示形式は「名称（サブスクリプション名 - リソースグループ名）」とする。 |
| 5 | プルダウンを閉じ、選択済みの Foundry にマウスを合わせる。 | 選択状態の表示は幅に応じて末尾を省略し、マウスオーバー時には表示文字列の全文をツールチップに表示する。 |

## 受け入れ条件

- 保存済みの Foundry 一覧・選択済み Foundry・モデル一覧が存在しない場合に Azure から取得する。
- 取得開始時から保存完了まで、進捗モーダルを表示する。
- 進捗モーダルは「Foundry一覧の取得」と「デプロイモデルの取得」の2行を、開いた時点から完了まで表示する。各行は「待機中」「取得中」「完了」を表示し、取得中の行には回転表示を付ける。モーダルの大きさは完了まで変えず、結果は各行の右側に表示する。経過時間は表示しない。
- 「Foundry一覧の取得」の完了時に、取得した Foundry の件数を表示する。
- Foundry 一覧は、参照可能なすべての Foundry を全ページ取得し、サブスクリプション名、Foundry 名の昇順に並べる。選択先のモデル一覧は全ページを取得し、選択先のすべてのデプロイ済みモデルを含める。
- 一覧の最初の Foundry を選択先とし、一覧の取得完了後にモデル取得を開始する。
- 「デプロイモデルの取得」に、選択した Foundry の名称と取得したモデルの累積件数を表示する。
- 処理中は閉じるボタン・Escape・モーダル外クリックでモーダルを閉じない。
- Foundry一覧・選択済み Foundry・選択先の全モデルをファイルに保存し、画面の内容と一致させる。
- 一覧と選択先の全モデルの取得、および必要なファイル保存のすべてが成功した後に結果を確定する。
- 保存成功後はモーダルを自動で閉じ、Home画面に結果を表示する。
