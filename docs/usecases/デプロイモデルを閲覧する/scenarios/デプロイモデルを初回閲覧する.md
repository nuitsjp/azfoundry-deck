# デプロイモデルを初回閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が Home画面を表示し、保存済みの Foundry 一覧・選択済み Foundry・モデル一覧が存在しない。参照可能な Foundry が1件以上存在する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | ログイン済みの状態で Home画面を初めて表示する。 | 「デプロイモデルを取得しています」という進捗モーダルを開き、サブスクリプションの検索を開始する。「サブスクリプションを検索中」と発見件数を表示する。 |
| 2 | モーダルで取得の進捗を確認する。 | 見つかったサブスクリプションを一覧へ追加し、各行に名称と「待機中」「Foundry取得中」を表示する。最大8件を並列に処理し、完了した行は一覧から削除して完了件数を更新する。最初に見つかった Foundry を選択し、残りの取得と並行して全デプロイ済みモデルを取得する。モーダルに選択先とモデル取得の進捗も表示する。 |
| 3 | 取得と保存の完了を確認する。 | 全 Foundry と選択先の全モデルの取得後、ファイルへの保存状況を表示する。保存成功後にモーダルを自動で閉じ、Home画面に Foundry のプルダウンと選択先の全モデルを表示する。 |
| 4 | Foundry のプルダウンを開く。 | 取得したすべての Foundry を、各項目の全文が読める状態で表示する。表示形式は「名称（サブスクリプション名 - リソースグループ名）」とする。 |
| 5 | プルダウンを閉じ、選択済みの Foundry にマウスを合わせる。 | 選択状態の表示は幅に応じて末尾を省略し、マウスオーバー時には表示文字列の全文をツールチップに表示する。 |

## 受け入れ条件

- 保存済みの Foundry 一覧・選択済み Foundry・モデル一覧が存在しない場合に Azure から取得する。
- 取得開始時から保存完了まで、進捗モーダルを表示する。
- サブスクリプション検索の「検索中」「検索完了」と発見件数を表示し、検索中は総数が未確定であることを示す。
- 発見したサブスクリプションを発見順に一覧へ追加する。完了した行は削除し、残った行の順序を維持する。
- 各行にサブスクリプション名、処理状態、発見した Foundry の件数を表示する。
- 「完了したサブスクリプション数／発見したサブスクリプション数」を、一覧から削除した行も含めて集計して表示する。
- Foundry取得は最大8並列とし、同時実行の枠を待つサブスクリプションは「待機中」、処理開始後は「Foundry取得中」と表示する。全ページ取得後は一覧から削除し、各行の状態と削除は実際の開始・完了に合わせる。
- Foundry 一覧と選択先のモデル一覧は全ページを取得し、参照可能なすべての Foundry と選択先のすべてのデプロイ済みモデルを含める。
- 最初に発見した Foundry を一度だけ選択し、残りの Foundry取得完了を待たずにモデル取得を開始する。
- 選択した Foundry の名称、モデル取得の「待機中」「取得中」「完了」、取得したモデル件数を表示する。
- ファイル保存の「待機中」「保存中」「完了」を表示する。
- 処理中は閉じるボタン・Escape・モーダル外クリックでモーダルを閉じない。
- Foundry一覧・選択済み Foundry・選択先の全モデルをファイルに保存し、画面の内容と一致させる。
- 一覧と選択先の全モデルの取得、および必要なファイル保存のすべてが成功した後に結果を確定する。
- 保存成功後はモーダルを自動で閉じ、Home画面に結果を表示する。
