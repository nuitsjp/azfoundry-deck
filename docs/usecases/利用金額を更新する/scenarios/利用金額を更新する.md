# 利用金額を更新する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が Home画面を表示し、選択中の Foundry のサブスクリプションの利用金額の取得が完了している（金額または取得失敗を表示している）。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | `This month` の金額の右にある「Refresh cost」ボタンにマウスを合わせて押す。 | ツールチップに「Refresh cost」を表示する。押されると、選択中の Foundry のサブスクリプションの当月の利用金額を Azure Cost Management から取得し直し、金額の位置に回転表示と `Loading...` を表示して「Refresh cost」ボタンを無効にする。進捗モーダルは開かない。 |
| 2 | 取得の完了を確認する。 | 取得が完了した時点で、利用者の追加操作なしに金額の位置へ取得した金額を表示し、「Refresh cost」ボタンを有効にする。 |

## 受け入れ条件

- 取得し直すのは選択中の Foundry のサブスクリプションの利用金額だけとし、Foundry 一覧、デプロイ済みモデル、容量上限情報、接続情報は取得し直さず、表示も変えない。モデル件数と最終取得日時も変えない。
- 取得中も、Foundry の変更、モデル一覧の操作、コピーボタンなど他の操作を受け付ける。
- 取得中に別の Foundry を選んだ場合は、更新前の Foundry の取得結果を表示せず、選んだ Foundry のサブスクリプションの利用金額を表示する。
- 取得に失敗した場合は、「デプロイモデルを閲覧する」の共通の受け入れ条件どおり金額の位置に `COST_LOAD_FAILED: 理由` を表示し、「Refresh cost」ボタンを有効にする。もう一度押すと取得し直す。
- 利用金額は状態ファイルに保存しない。
