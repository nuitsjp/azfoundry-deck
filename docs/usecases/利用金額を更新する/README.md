# 利用金額を更新する

## 主アクター

Azure にログイン済みの Foundry 運用者。

## 目的

選択中の Foundry のサブスクリプションの当月の利用金額を Azure Cost Management から取得し直し、Home画面の金額を最新にする。

## 前提

Azure にログイン済みで、Home画面に選択中の Foundry のサブスクリプションの行（`Subscription ID` と `This month`）を表示している。

## 共通の受け入れ条件

- `This month` の金額表示欄の右に「Refresh cost」ボタン（マウスオーバー時にツールチップで名称を表示するアイコンボタン）を置く。
- 利用金額の取得中は「Refresh cost」ボタンを無効にする。取得の成功後と失敗後は有効にし、失敗後の再試行もこのボタンで行う。
- 利用金額の算出方法、表示形式、取得中と失敗時の表示、メモリだけでの保持は「デプロイモデルを閲覧する」の共通の受け入れ条件に従う。
- 利用金額の更新は、デプロイ済みモデルの一覧・容量上限情報・接続情報・状態ファイルを取得し直したり変更したりしない。
