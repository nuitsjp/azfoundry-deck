# インストールを完了して起動方法を選ぶ

- 種別: 主成功
- UI確認: 要

## 開始条件
利用者がインストーラーをダウンロード済みである。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | インストーラーを実行し、インストール先を選んで進める。 | アプリを配置し、スタートメニューに自動登録する。 |
| 2 | インストール完了画面を確認する。 | 「アプリを起動する」をチェックあり、「デスクトップにショートカットを作成する」をチェックなしで表示する。 |
| 3 | 必要に応じてチェックを変更し、「完了」を押す。 | 選択されていればデスクトップにショートカットを作成し、選択されていればアプリを起動して、インストーラーを閉じる。 |

## 受け入れ条件
- 完了画面の選択項目は上記の2つだけとする。
- スタートメニューへの登録は選択項目にせず、自動で行う。
- リリースノートの表示項目やリンクは設けない。
- アプリ起動・ショートカット作成は、それぞれのチェックに従う。
- アンインストール時には、作成したデスクトップとスタートメニューのショートカットを削除する。
