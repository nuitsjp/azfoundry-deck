# 新規リソースグループとFoundryを作成する

- 種別: 主成功
- UI確認: 要

## 開始条件

- Home画面が表示されている。既存 Foundry が0件でも開始できる。
- 指定するリソースグループ名と Foundry 名で新規作成できる。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | Home画面の「Add Foundry」を押す。 | 作成モーダルを開き、選択中テナントのサブスクリプション候補を取得して先頭を選択する。選択したサブスクリプションの Foundry 作成候補リージョンを取得し、East US 2（eastus2）を初期選択する。Keyword に sample を入れ、Resource group name に rg-sample-eastus2、Foundry name に foundry-sample-eastus2 を最初から表示する。 |
| 2 | サブスクリプション、リージョン、キーワードを指定し、必要に応じてリソースグループ名と Foundry 名を直接編集する。 | サブスクリプション変更時はリージョン候補を取得し直す。キーワードまたはリージョンの変更時は、直接編集済みの値も含めて両方の名前を再生成する。必要な入力が有効になったら「Create」を有効にする。 |
| 3 | 「Create」を押す。 | 入力を確定し、作成モーダルの前面に「Creating Foundry」の進捗モーダルを表示する。「Create resource group」「Create Foundry」「Update Home」の3行に、待機・実行中・完了を表示する。指定先にリソースグループを作成し、その中に Foundry を作成する。実行中は重複実行とモーダルの閉鎖を防ぐ。 |
| 4 | 作成完了後のHome画面を確認する。 | 作成結果を Foundry 一覧に反映して新しい Foundry を選択する。一覧と選択を保存し、デプロイ一覧を取得して表示する。更新完了後、作成・進捗モーダルを閉じる。 |

## 受け入れ条件

- 指定したサブスクリプションに、新規リソースグループと、その中の Foundry が作成される。
- リージョンは両リソース共通とし、デフォルトは eastus2 とする。候補にない場合は未選択とし、別のリージョンを自動選択しない。
- リージョンの表示名と正式識別名を区別する。画面は表示名を使い、作成要求と命名は正式識別名を使う。
- サブスクリプションのリージョン一覧と AIServices／S0 の対応リージョン・制限を照合して候補を表示する。
- キーワードは英数字・ハイフンを使い、名前を `rg-<キーワード>-<リージョン識別名>` と `foundry-<キーワード>-<リージョン識別名>` で生成する。キーワードは小文字化し、英数字・ハイフン以外はハイフンに置換し、連続および先頭・末尾のハイフンを除く。
- 両方の名前は直接編集でき、キーワードまたはリージョンを変更したときは両方を再生成する。
- 必須入力が空の場合は作成を実行できない。
- 「Cancel」または「×」で作成開始前に閉じた場合、リソースを作成せず、元のHome画面へ戻る。
- 両リソースの作成が完了するまで、作成成功として表示しない。進捗モーダルは Escape や外側クリックで閉じない。
- Azure Resource Graph への反映を待たず、作成結果を一覧に反映する。表示順と名称の表示形式は既存の Foundry 一覧に合わせる。
- Foundry 一覧と選択は保存し、デプロイ一覧はメモリだけに保持する。
- 作成途中で失敗しても、作成済みのリソースグループを自動削除しない。
