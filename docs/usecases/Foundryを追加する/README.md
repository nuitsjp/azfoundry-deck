# Foundryを追加する

## 主アクター

Azure にログイン済みの Foundry 運用者。

## 目的

新規リソースグループと、その中に配置する Foundry を作成し、Home画面からモデルの管理を始められるようにする。

## 前提

- 利用対象のテナントが選択されている。
- 作成先のサブスクリプションで、リソースグループと Foundry を作成する権限がある。
- 作成対象は Foundry リソース（AIServices、SKU S0）であり、プロジェクトやモデルは同時作成しない。
