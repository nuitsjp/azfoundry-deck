# Foundryが存在しない状態へ一覧を更新する

- 種別: 拡張
- UI確認: 要

## 分岐条件
ログイン済みの利用者が、Foundry 一覧とデプロイ済みモデルを表示した Home画面で「Foundry一覧を更新」ボタンを押す。Foundry 一覧の取得は成功したが、参照可能な Foundry が1件もない。ファイルの保存と削除が成功する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | Foundry のプルダウンの右にある「Foundry一覧を更新」ボタンを押す | 「Foundry一覧を更新しています」という進捗モーダルを開き、Foundry 一覧の取得を開始する。進捗は主成功と同じ形式で表示する。 |
| 2 | モーダルで取得の進捗を確認する | Foundry 一覧の取得が完了し、更新後の Foundry が0件であることを確認する。選択先がないため、モデルの取得は行わず、「デプロイモデルの取得」は「待機中」のままにする。 |
| 3 | 保存の完了を確認する | 空の一覧と取得日時を保存し、保存済みのすべての Foundry のモデルファイルを削除する。保存成功後にモーダルを自動で閉じ、Foundry のプルダウンとデプロイ済みモデルの一覧を空の状態で表示する。 |

## 受け入れ条件
- 更新後の一覧が0件の場合を、エラーとして扱わない。`FOUNDRY_LOAD_FAILED` を表示しない。
- 進捗モーダルは、主成功と同じ形式で表示する。「デプロイモデルの取得」は「待機中」のままにする。
- 空の一覧、選択なし、空のモデル、Foundry 一覧の最終取得日時を状態ファイルに保存し、画面の内容と一致させる。
- 更新後の一覧に含まれない Foundry のモデルファイルを、すべて削除する。
- 保存が成功するまで、更新前の Foundry 一覧・選択・モデル表示を維持する。
- 保存成功後、Foundry のプルダウンは選択なしで選択肢を持たず、デプロイ済みモデルの一覧は0件の空の状態で表示する。「モデルを更新」ボタンは無効にし、「Foundry一覧を更新」ボタンは使える状態にする。
- アプリケーションを再起動した場合も、同じ表示にし、Azure から取得し直さない。
