# Foundry一覧を更新する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が Foundry 一覧とデプロイ済みモデルを表示した Home画面で「Foundry一覧を更新」ボタンを押し、Azure から更新後の一覧を取得した時点で、選択中の Foundry がその一覧に含まれる。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | Foundry のプルダウンの右にある「Foundry一覧を更新」ボタンを押す。 | 「Foundry一覧を更新しています」という進捗モーダルを開き、Foundry 一覧の取得を開始する。「Foundry一覧の取得」を「取得中」、「デプロイモデルの取得」を「待機中」で表示する。 |
| 2 | モーダルで取得の進捗を確認する。 | Foundry 一覧の取得後、「Foundry一覧の取得」を「完了」と取得した Foundry の件数で表示する。 |
| 3 | 取得と保存の完了を確認する。 | 全 Foundry の取得後、選択中の Foundry が一覧に含まれることを確認し、選択とモデルを維持する。「デプロイモデルの取得」は「待機中」のままにする。一覧に含まれない Foundry のモデルファイルを削除した後、更新後の状態を保存する。成功後にモーダルを自動で閉じ、更新後の Foundry 一覧と最終取得日時を画面に反映する。 |
| 4 | Foundry のプルダウンを開く。 | 更新後のすべての Foundry を、各項目の全文が読める状態で表示する。 |

## 受け入れ条件

- Foundry 一覧の取得の進捗は、初回閲覧と同じ形式で表示する。Foundry 一覧は全ページを取得し、サブスクリプション名、Foundry 名の昇順に並べる。
- 選択とモデル表示を変更せず、モデルを Azure から取得しない。「デプロイモデルの取得」は「待機中」のまま、保存の成功後にモーダルを閉じる。
- 更新後の一覧に含まれない Foundry のモデルファイルを削除する。
- 更新後の Foundry 一覧、選択、表示するモデル、Foundry 一覧の最終取得日時を状態ファイルに保存し、画面の内容と一致させる。
- モデルの最終取得日時を変更しない。
- 一覧の取得、必要なファイル削除と保存のすべてが成功した後に結果を確定する。
- 保存が成功するまで、更新前の Foundry 一覧・選択・モデル表示を維持する。
- 保存成功後はモーダルを自動で閉じる。
- アプリケーションを再起動した場合も、更新後の Foundry 一覧・選択・モデル・最終取得日時を復元する。
