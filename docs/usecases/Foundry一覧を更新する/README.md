# Foundry一覧を更新する

## 主アクター

Foundry の運用者。

## 目的

Azure から Foundry 一覧を取得し直し、Home画面の一覧を最新にする。

## 前提

Azure にログイン済みで、Home画面に Foundry 一覧を表示している。

## 共通の受け入れ条件

- Foundry のプルダウンの右に「Foundry一覧を更新」ボタン（マウスオーバー時にツールチップで名称を表示するアイコンボタン）を置く。
- Foundry 一覧の更新中は、閉じるボタン・Escape・モーダル外クリックで進捗モーダルを閉じず、Foundry の変更と更新操作を受け付けない。
- 最終取得日時の表示は「デプロイモデルを閲覧する」の共通の受け入れ条件に従う。
