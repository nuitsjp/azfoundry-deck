# ブラウザーでAzureにサインインする

- 種別: 主成功
- UI確認: 要

## 開始条件
アプリ起動直後で、保存済みのログイン情報がない。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | アプリを起動する | Home を背景に、「Azureにログイン」ボタンだけを持つログインモーダルを自動で表示する。モーダルは閉じる操作ができない |
| 2 | 「Azureにログイン」を押す | 既定のブラウザーで Microsoft のサインイン画面を開き、モーダルの中身をプログレスリングと「ブラウザーでサインインしてください」に置き換える |
| 3 | ブラウザーでサインインに成功する | 認証結果を受け取り、Azure Resource Manager 向けのアクセストークンとテナント名の取得に成功したらログイン成功を確定し、ログイン情報を OS のクレデンシャルマネージャーに保存する |
| 4 | 画面に戻る | モーダルを閉じて Home を表示する。ヘッダー右端にユーザーアイコン（マウスオーバーでアカウント名）を、その左に右寄せでテナント名（テナントIDではなく Entra ID の表示名）を表示する |

## 受け入れ条件
- 手順4のアカウント名とテナント名が、サインインしたアカウントのものと一致する。
- 手順3のトークン取得、テナント名の取得、保存のいずれかに失敗した場合は、ログイン済みにならず、モーダルを開いたまま、エラーのコードと理由を表示してボタンを再び押せる状態に戻す。失敗の種類による文言の区別はしない。
- 手順3の後、OS のクレデンシャルマネージャーにこのアプリのログイン情報が存在する。
