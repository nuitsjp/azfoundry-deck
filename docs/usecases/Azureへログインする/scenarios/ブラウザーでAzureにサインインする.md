# ブラウザーでAzureにサインインする

- 種別: 主成功
- UI確認: 要

## 開始条件
アプリ起動直後で、保存済みのログイン情報がない。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | アプリを起動する | 「Azureにログイン」ボタンだけを持つ未ログイン画面を表示する |
| 2 | 「Azureにログイン」を押す | 既定のブラウザーで Microsoft のサインイン画面を開き、画面に「ブラウザーでサインインしてください」と表示してボタンを無効にする |
| 3 | ブラウザーでサインインに成功する | 認証結果を受け取り、Azure Resource Manager 向けのアクセストークンを1回取得してログイン成功を確定し、ログイン情報を OS のクレデンシャルマネージャーに保存する |
| 4 | 画面に戻る | ログイン済み画面に、サインインしたアカウント名とテナントIDを表示する |

## 受け入れ条件
- 手順4のアカウント名とテナントIDが、サインインしたアカウントのものと一致する。
- 手順3のトークン取得または保存に失敗した場合は、ログイン済みにならず未ログイン画面に戻り、失敗理由を表示する。
- 手順3の後、OS のクレデンシャルマネージャーにこのアプリのログイン情報が存在する。
