# ブラウザーでAzureにサインインする

- 種別: 主成功
- UI確認: 要

## 開始条件
アプリが未ログインで、保存済みのログイン情報がない。サインインするアカウントについて、Azure Resource Manager から取得されるテナント一覧に1件だけ存在する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | アプリを起動する | Home を背景に、閉じられないログインモーダルと「Azureにログイン」ボタンを表示する。 |
| 2 | 「Azureにログイン」を押す | 既定のブラウザーにサインイン画面を開く。モーダルには進行中の表示と「ブラウザーでサインインしてください」を表示する。 |
| 3 | ブラウザーでサインインを完了する | 認証結果を受け取り、トークンと認証記録を保存する。Azure Resource Manager からテナント一覧を取得する。 |
| 4 | （操作なし） | 一覧の唯一のテナントを自動選択し、選択を保存する。ログインモーダルを閉じて Home を表示する。ヘッダー右側にテナントのプルダウンとユーザーアイコンを表示する。 |

## 受け入れ条件
- テナント選択画面を表示せず、一覧の唯一のテナントを選択する。
- プルダウンの選択値と表示名は、取得したテナント一覧の内容と一致する。
- ユーザーアイコンのマウスオーバーで、サインインしたアカウント名を表示する。
- テナント選択完了後、そのテナントの Foundry 閲覧を開始する。
- 認証・一覧取得・保存に失敗した場合は、Home の閲覧を開始せず、ログインモーダルにエラーのコードと理由を表示し、再試行できる。
- 一覧が0件の場合は、利用可能なテナントがない旨を表示し、Home の閲覧を開始しない。
