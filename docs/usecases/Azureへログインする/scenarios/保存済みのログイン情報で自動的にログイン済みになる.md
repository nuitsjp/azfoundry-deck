# 保存済みのログイン情報で自動的にログイン済みになる

- 種別: 拡張
- UI確認: 不要

## 分岐条件
シナリオ「ブラウザーでAzureにサインインする」の手順1（アプリ起動）の時点で、OS のクレデンシャルマネージャーにこのアプリのアカウント識別情報（`AuthenticationRecord`）が保存されている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | アプリを起動する | 保存済みのアカウント識別情報を読み出し、Azure SDK の永続キャッシュからブラウザーを開かずにアクセストークンを取得し、テナント名を取得する。この間、ログインモーダルは表示しない |
| 2 | （操作なし） | 手順1がすべて成功したら、ログイン済みを確定し、Home を表示する。ヘッダー右端にユーザーアイコン（マウスオーバーでアカウント名）を、その左に右寄せでテナント名を表示する |

## 受け入れ条件
- 再起動後、ブラウザー操作なしに、シナリオ「ブラウザーでAzureにサインインする」の手順4と同じ画面（Home、右上のテナント名とユーザーアイコン）になる。
- アカウント識別情報の読み出し、トークンの取得、テナント名の取得のいずれかに失敗した場合は、ログイン済みにならず、ブラウザーを自動で開かない。通常のログインモーダル（主成功の手順1と同じ）を開き、エラーのコードと理由を表示する。
- 失敗時も保存済みのアカウント識別情報は削除しない（次の手動ログインの成功で上書きする）。
- 起動中の取得の間は、モーダルもスピナーも表示せず、ヘッダー右が空の Home を表示する。
