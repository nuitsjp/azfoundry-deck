# 保存済みのログイン情報で自動的にログイン済みになる

- 種別: 拡張
- UI確認: 不要

## 分岐条件
起動時に、このアプリの認証記録・テナント一覧・前回選択したテナントが保存されている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | アプリを起動する | 保存済みの認証記録からブラウザーを開かずにトークンを取得し、保存済みのテナント一覧と選択を読み込む。この間はモーダルやスピナーを表示せず、ヘッダー右側が空の Home を表示する。 |
| 2 | （操作なし） | 保存した選択を復元し、Home にテナントプルダウンとユーザーアイコンを表示する。 |

## 受け入れ条件
- 起動時に ARM のテナント一覧を取得しない。
- 保存済みの一覧が複数件でも、前回の選択を復元して選択画面を表示しない。
- 認証記録のテナント ID を選択の復元に使わない。
- 読み出しやトークン取得に失敗した場合は、ブラウザーを自動で開かず、ログインモーダルにエラーのコードと理由を表示する。
- 復元の失敗時も保存情報を自動削除しない。
