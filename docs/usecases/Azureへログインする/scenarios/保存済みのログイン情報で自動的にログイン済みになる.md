# 保存済みのログイン情報で自動的にログイン済みになる

- 種別: 拡張
- UI確認: 不要

## 分岐条件
アプリ起動時に、このアプリの認証記録と、前回選択したテナントが保存されている。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | アプリを起動する | 保存済みの認証記録から、ブラウザーを開かずにトークンを取得し、テナント一覧を取得する。この間、ログインモーダルやスピナーは表示せず、ヘッダー右側が空の Home を表示する。 |
| 2 | （操作なし） | 前回選択したテナントが取得した一覧に存在することを確認し、その選択を復元する。Home にテナントのプルダウンとユーザーアイコンを表示する。 |

## 受け入れ条件
- 一覧に複数テナントがあっても、前回の選択が存在すればテナント選択画面を表示しない。
- 認証記録のテナント ID ではなく、保存した選択を復元する。
- 認証記録の読み出し、トークン取得、一覧取得に失敗した場合は、ブラウザーを自動で開かず、ログインモーダルにエラーのコードと理由を表示する。
- 失敗時も保存済みの認証記録を削除しない。
- 保存した選択が利用できない場合は、一覧が1件ならそのテナントを自動選択し、複数件ならテナント選択画面を表示する。0件なら利用可能なテナントがない旨を表示する。
