# サインイン時に複数テナントが存在する

- 種別: 拡張
- UI確認: 要

## 分岐条件
「ブラウザーでAzureにサインインする」で、認証後に取得したテナント一覧に2件以上存在する。

## 手順
| # | アクター | システム |
| --- | --- | --- |
| 1 | ブラウザーでサインインを完了する | 認証結果と認証記録を保存し、テナント一覧を取得する。認証済みになった後、ログインモーダルをテナント選択画面に切り替える。 |
| 2 | 利用するテナントを選ぶ | 取得した一覧から選択できるようにする。初期状態では未選択とし、選択するまで確定ボタンを無効にする。 |
| 3 | 選択を確定する | 選択したテナントを保存し、テナント選択画面を閉じる。Home と、選択したテナントのプルダウン、ユーザーアイコンを表示する。 |

## 受け入れ条件
- 認証記録のテナントや一覧の先頭を自動選択しない。
- テナント選択画面には、取得したすべてのテナントを表示名で提示する。
- テナント選択画面を閉じるだけで、未選択のまま Home に進むことはできない。
- 選択完了前に Foundry の閲覧・操作を開始しない。
- 選択保存に失敗した場合は、選択画面にエラーを表示し、選択値を保持して再試行できる。
- 選択完了後、そのテナントの Foundry 閲覧を開始する。
