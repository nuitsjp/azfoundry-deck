# Azureへログインする

## 主アクター
Azure 上の Microsoft Foundry を管理する運用者（Azure アカウントを持つ個人）

## 目的
Azure の認証済み状態をアプリ内で確立し、利用対象のテナントを決定する。認証情報・テナント一覧・選択したテナントを次回起動以降も引き継ぐ。

## 前提
- 利用者は、Azure を利用できる個人 Microsoft アカウント、または職場・学校アカウントを持ち、Azure サブスクリプションへのアクセス権がある。
- 端末に既定のブラウザーがあり、インターネットに接続できる。
- アプリは Windows デスクトップ版として動作する。

## 共通の受け入れ条件
- 認証は Azure SDK for Go の `InteractiveBrowserCredential` で行う。
- ブラウザーでのサインイン時に ARM からテナント一覧を取得し、ID と表示名を保存する。通常起動時やテナント変更時には一覧を取得し直さない。
- 認証記録のテナント ID を、一覧との照合や利用対象テナントの決定に使わない。
- アカウント識別情報は OS のクレデンシャルマネージャーに、トークンは Azure SDK のアプリ固有の永続キャッシュに保存する。パスワードやトークンを画面・ログ・設定ファイルへ平文で出力しない。
- 選択したテナントを保存し、以降の Azure リソース操作はそのテナントを対象とする。
- テナント表示には、保存した一覧の表示名を使う。
- 認証成功とテナント選択完了を区別する。テナント未選択の間は、Foundry の閲覧・操作を開始しない。
- 失敗時にダミーの成功状態へ切り替えない。
