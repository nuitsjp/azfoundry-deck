# Foundryを変更し再閲覧する

- 種別: 拡張
- UI確認: 要

## 分岐条件

ログイン済みの利用者が Home画面で現在と異なる Foundry を選択し、変更先のモデルの保存ファイルが存在する。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | Foundry のプルダウンを開く。 | 保持している Foundry 一覧と現在の選択を表示する。 |
| 2 | 現在と異なる Foundry を選択する。 | プルダウンを閉じ、変更先のモデルを保存済みファイルから読み込む。取得の進捗モーダルは表示しない。 |
| 3 | 変更後の Foundry とデプロイ済みモデルを確認する。 | 変更先の選択とモデルを現在の状態ファイルに保存し、保存成功後に画面の選択とモデルを更新する。 |
| 4 | 選択済みの Foundry にマウスを合わせる。 | 選択表示の全文をツールチップに表示する。 |

## 受け入れ条件

- 保持している Foundry 一覧から変更先を選択できる。
- Foundry 一覧・モデルの Azure からの取得を実行しない。
- 表示する変更先のモデルは、保存済みモデルファイルの内容と完全に一致する。
- 取得の進捗モーダルを表示しない。
- 変更先のモデルファイルを再保存せず、ファイルの内容と更新時刻を維持する。
- 変更前の Foundry のモデルの保存も保持する。
- ファイルの読み込みと選択状態の保存が完了するまで、変更前に確定した Foundry の選択とモデル表示を維持する。
- ファイルの読み込みと選択状態の保存のすべてが成功した後に結果を確定する。
- 現在の状態ファイルと画面の選択・モデルを一致させる。
- アプリケーションを再起動した場合も、変更後の選択とモデルを復元する。
