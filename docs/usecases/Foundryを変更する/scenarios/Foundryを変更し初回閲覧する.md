# Foundryを変更し初回閲覧する

- 種別: 主成功
- UI確認: 要

## 開始条件

ログイン済みの利用者が Home画面で現在と異なる Foundry を選択し、変更先のモデルの保存ファイルが存在しない。

## 手順

| # | アクター | システム |
| --- | --- | --- |
| 1 | Foundry のプルダウンを開く。 | 保持している Foundry 一覧と現在の選択を表示する。 |
| 2 | 現在と異なる Foundry を選択する。 | 変更先のモデルの保存ファイルが存在しないことを確認し、プルダウンを閉じて進捗モーダルを開く。変更先のすべてのデプロイ済みモデルを Azure から取得する。 |
| 3 | モーダルで取得の進捗を確認する。 | 「デプロイモデルの取得」を「取得中」で表示し、変更先の名称と累積件数を表示する。全モデルの取得後に「完了」にする。 |
| 4 | 完了した Foundry とデプロイ済みモデルを確認する。 | 変更先の全モデルと選択をファイルに保存する。保存成功後に画面の選択とモデルを更新し、進捗モーダルを閉じる。 |
| 5 | 選択済みの Foundry にマウスを合わせる。 | 選択表示の全文をツールチップに表示する。 |

## 受け入れ条件

- 保持している Foundry 一覧から変更先を選択できる。
- Foundry 一覧を再取得しない。
- 変更先のモデルの保存ファイルが存在しない場合、変更先のデプロイ済みモデルを Azure から全ページ取得する。
- 進捗モーダルは「デプロイモデルの取得」の1行だけを表示し、「取得中」「完了」、変更先の名称、累積件数を示す。取得中の行には回転表示を付け、結果は行の右側に表示する。
- Foundry 一覧の取得の進捗を表示しない。
- 処理中は Foundry を再変更できず、閉じるボタン・Escape・モーダル外クリックで進捗モーダルを閉じない。
- 処理が完了するまで、変更前に確定した Foundry の選択とモデル表示を維持する。
- 変更先のすべてのデプロイ済みモデルと選択をファイルに保存し、画面の内容と一致させる。
- モデルの取得と必要なファイル保存のすべてが成功した後に結果を確定する。
- 変更前の Foundry のモデルの保存も保持し、戻ったときにファイルから表示できるようにする。
